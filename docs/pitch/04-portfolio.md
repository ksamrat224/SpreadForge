# Portfolio

## Simple explanation

Portfolio turns raw balances into useful information. It helps the user understand what they own, what is performing well, and where risk is concentrated.

## Main features

- Total portfolio value
- Total profit or loss
- Percentage return
- Available virtual USDC
- Invested value
- Allocation bars
- Detailed holdings table
- Best performer
- Position needing attention
- Strongest one-day momentum
- One-click return to the correct Paper Trading market

## Holdings information

Each row can show:

- Asset and quantity
- Average purchase cost
- Current price
- Current market value
- Portfolio allocation
- Unrealized profit or loss
- One-day price change
- Momentum label
- Volatility label

## Momentum is not a prediction

Momentum describes the last one-day price movement:

| Change     | Meaning                  |
| ---------- | ------------------------ |
| Above +3%  | Strong upward movement   |
| +1% to +3% | Upward movement          |
| -1% to +1% | Neutral                  |
| -3% to -1% | Downward movement        |
| Below -3%  | Strong downward movement |

Volatility uses the one-day high-to-low range. It is labeled low, moderate, or high.

## Reliable partial results

SpreadForge fetches data only for assets the user owns. One failed price request does not hide every other holding. If a price is unavailable, the asset remains visible and totals are clearly marked as partial.
